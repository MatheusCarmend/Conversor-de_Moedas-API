# Conversor de Moedas API

API para conversão de moedas em tempo real utilizando integração com serviço externo.

## Tecnologias
- C#
- ASP.NET Core
- Swagger

## Funcionalidades
- Conversão entre moedas
- Validação de entrada
- Tratamento de erros

## Como executar
1. Clone o repositório
2. Execute o projeto
3. Acesse /swagger
